# OT 生存包数值说明

适用于完整版与适配版 1.0.0。下列数值以完整版为准，适配版的不同之处见文末“适配版差异”。

## 安装与基本规则

| 版本 | 最低游戏版本 | 安装文件 |
| --- | --- | --- |

- 四项状态默认开启，每名玩家的数值独立。
- 数值范围均为 0–100；温度数值是本包的刻度，不是摄氏度。
- 生存、冒险模式正常生效；创造、旁观模式不自动消耗，也不承受本包惩罚。
- 下文按每秒 20 游戏刻换算。游戏卡顿时，实际等待时间可能变长。

## 面板与位置调整

### 获取面板

在工作台中放入 6 个普通泥土：相邻两行，每行三个，合成 1 个生存状态面板。启用配方解锁的世界中，获得普通泥土即可解锁配方。

也可用命令获取：

```mcfunction
/give @s ot:status_panel
```

手持面板使用，生存和创造模式都可以打开。

| 玩家权限 | 可用功能 | 生效范围 |
| --- | --- | --- |
| 普通玩家 | 调整状态条位置 | 仅自己 |
| 管理员（操作员） | 调整状态条位置、管理状态条开关 | 位置仅自己，开关影响全世界 |

管理员首页有“状态条开关”和“调整我的状态条位置”两个按钮，不要求创造模式。修改后需要保存，直接关闭页面不会保存。

### 默认位置与滑块

坐标以屏幕底部中央为起点，使用 HUD 逻辑单位，不是实际屏幕像素。

| 显示 | 桌面居中 HUD | 携带／居中触控 HUD |
| --- | --- | --- |
| 体力条 | `[-95,-1]` | `[-105,-1]` |
| 理智条 | `[95,-1]` | `[105,-1]` |
| 温度、口渴 | `[0,-32]` | `[0,-32]` |

| 调整方向 | 相对默认位置的范围 | 每档 | 可选值数量 |
| --- | --- | ---: | ---: |
| 左右 | −100～＋100，负数向左 | 1 | 201 |
| 上下 | −75～＋75，负数向上 | 1 | 151 |

- 体力、理智各有左右和上下滑块；温度、口渴各有上下滑块。
- 只有滑块区域滚动，底部“恢复默认位置”和绿色“保存位置”始终可见。
- 没有实时预览。保存后回到游戏查看；勾选“恢复默认位置”再保存，会清除六项个人微调。
- 默认布局按游戏的 HUD 布局选择，不按手机型号选择。更换屏幕比例或 GUI 缩放后，可用滑块重新校准。
- 位置会保存，更新包不会自动清除已有微调。

### 关闭状态条会怎样？

关闭某项时，会同时隐藏状态条、冻结数值，并停止该项的消耗、恢复、限制和惩罚。

- 关闭体力会解除本包造成的跳跃限制；关闭温度会停止冷热对其他状态的影响。
- 已经施加的短时药效会自然结束，不立即清除。缺水反胃最多约残留 10 秒。
- 各项开关独立。关闭体力后，口渴仍按动作失水，温度仍按动作产热并造成极端温度伤害。

## 体力

### 消耗与恢复

下表为未计护甲负担的基础值；穿戴重甲时，跑、跳、游泳按下一节加成。

| 活动 | 体力变化 |
| --- | --- |
| 冲刺 | −3／秒 |
| 游泳姿态 | −4／秒；与冲刺同时发生时只计游泳 |
| 实际起跳 | −2／次；按住跳跃不重复扣除 |
| 近战挥空 | −1／次 |
| 近战命中 | −2／次；同一次挥动不再扣挥空费用 |
| 攻击、投射物、坠落或爆炸造成的外伤 | −2／次；缺水、温度、饥饿等持续伤害不扣这笔体力 |
| 挖掘 | −2／秒；成功破坏方块至少 −1／块，已扣的挖掘费用计入其中 |
| 持续拉原版弓 | −1／秒 |
| 装填原版弩 | −2／秒；装填完成、取消或换物品后停止，已上膛持有不扣 |
| 行走、普通水中活动、鞘翅滑翔 | ＋4／秒 |
| 潜行或静止 | ＋8／秒；在水中仍为 ＋4／秒 |

### 护甲负担

| 穿着的护甲 | 每件增加跑／跳／游泳消耗 | 同材质四件套 |
| --- | ---: | ---: |
| 锁链甲 | ＋5% | ＋20% |
| 铜甲、钻石甲 | ＋7.5% | ＋30% |
| 金甲、铁甲 | ＋10% | ＋40% |
| 下界合金甲 | ＋12.5% | ＋50% |
| 皮革、海龟壳、鞘翅，以及未列出的装备 | 不增加 | 不增加 |

- 只统计头、胸、腿、脚四个装备槽；混穿逐件相加，最多 ＋50%。背包和副手里的护甲不算负担。
- 只增加冲刺、实际起跳和游泳的费用；普通行走、恢复速度、攻击、挖掘、拉弓和装填弩保持原规则。
- 例如全套铁甲：冲刺 −4.2／秒、游泳 −5.6／秒、跳跃 −2.8／次。全套下界合金甲分别为 −4.5／秒、−6／秒、−3／次。
- 换装后最多约 1 秒更新负担；体力耗尽时仍可按原速度恢复。

### 饥饿对恢复的影响

| 饱食度 | 恢复倍率 | 行走、普通水中活动、滑翔 | 潜行或静止（不在水中） |
| --- | ---: | ---: | ---: |
| 大于 6 | ×1 | ＋4／秒 | ＋8／秒 |
| 大于 0、不高于 6 | ×0.75 | ＋3／秒 | ＋6／秒 |
| 0 | ×0.5 | ＋2／秒 | ＋4／秒 |

表中为常温速度。饥饿与低温的恢复倍率相乘，吃饱后恢复正常；只影响恢复，不增加消耗，体力耗尽时也不会因此完全无法恢复。

### 哪些情况会暂停恢复？

| 情况 | 暂停时间 |
| --- | --- |
| 挥拳等待命中判定 | 约 0.1 秒；确认为挥空后立即恢复 |
| 近战命中 | 命中后 0.5 秒 |
| 上表中的外伤 | 最后一次外伤后 0.5 秒；连续受伤重新计时，不累加时长 |
| 挖掘、拉弓或装填弩 | 活动期间暂停恢复 |

暂停恢复不会免除原有体力消耗。体力已经耗尽时，无效的挖掘、攻击等尝试不会继续阻止恢复。

### 体力耗尽

| 项目 | 规则 |
| --- | --- |
| 进入限制 | 体力降到 0 |
| 跳跃、挖掘、攻击 | 禁止跳跃、阻止方块破坏及近战／投射物伤害；尝试阻止原版弓、弩使用，动作动画仍可能出现 |
| 冲刺、游泳 | 用缓慢 III 限速，普通行走保留；拉弓／装填弩时不反复叠加这项减速 |
| 解除限制 | 恢复到 20 |
| 常温、饱食度大于 6，静止恢复到 20 | 约 2.5 秒 |
| 常温、饱食度大于 6，行走、普通水中活动或滑翔恢复到 20 | 约 5 秒 |

温度为“冷”时，恢复速度 ×0.8；“寒冷”时 ×0.5。体力消耗不受此倍率影响。

## 口渴

### 日常与活动失水

平时每 20 秒失去 1 点口渴，即 −0.05／秒。以下活动费用在此基础上额外计算。

| 活动 | 额外失水 |
| --- | --- |
| 冲刺 | −0.075／秒；加上日常失水共 −0.125／秒 |
| 游泳姿态 | −0.1／秒；与冲刺同时发生时只计游泳 |
| 实际起跳 | −0.05／次 |
| 近战挥空／命中 | 分别 −0.025／−0.05／次，同一次挥动不重复扣 |
| 挖掘 | −0.05／秒；成功破坏方块至少 −0.025／块，已扣的挖掘费用计入其中 |
| 持续拉原版弓 | −0.025／秒 |
| 装填原版弩 | −0.05／秒；装填完成后停止 |

- 活动费用按“1 点体力消耗对应 0.025 点额外失水”设定，但两项独立计算。关闭体力不会免除活动失水。
- 护甲负担也按相同倍率增加跑／跳／游泳的活动失水，不增加日常失水；体力与口渴的开关仍互不依赖。
- 不同动作的费用相加，例如边跑、边跳、边挥拳；同一动作不会重复计费。
- 温度为“热”时，所有失水 ×1.25；“炎热”时 ×1.5。补水量不变。

### 补水

| 方式 | 恢复量 |
| --- | --- |
| 喝完水瓶 | ＋25 |
| 喝完牛奶桶 | ＋20 |
| 喝完普通饮用药水（非水瓶） | ＋5 |
| 吃完蘑菇煲、兔肉煲、甜菜汤或谜之炖菜 | ＋10 |
| 蜂蜜瓶、不祥之瓶 | 不补水 |
| 头部浸在淡水中 | ＋1／秒，代替持续失水；只有身体入水不算 |
| 头部浸在海水中 | 不补水，仍按日常与活动规则失水，不额外施加盐水惩罚 |
| 主世界露天雨／雷雨 | ＋0.1／秒，约 10 秒＋1；代替该时刻的失水，期间不额外扣活动失水 |

- 必须完整喝完或吃完，中途取消不补水。喷溅药水、滞留药水和普通水桶不算饮用。
- 淋雨与头部浸淡水不叠加。头部浸在海水中时，既不获得海水补水，也不获得头顶雨水补水。
- 头部浸水仍有原版溺水风险。
- 适配版水瓶和普通饮用药水均为 ＋20，详见“适配版差异”。

### 淡水与海水怎样区分？

- 按头部浸水位置的群系判定：普通、深层、暖、温、冷及冰冻海洋都算海水，其他群系的水按淡水处理；河流、冰冻河流仍是淡水。
- 海洋中的人工水池也按海水处理，陆地人工水池按淡水处理；水瓶不追溯取水来源，补水量保持原规则。
- 跨群系后约 1 秒内更新判定。无法读取水所在区域时不提供浸水补水，其他状态仍照常更新。

### 缺水惩罚

| 口渴值 | 伤害 | 额外效果 |
| --- | --- | --- |
| 大于 0、低于 20 | 每 5 秒扣 1 点生命 | 无 |
| 0 | 每 2 秒扣 1 点生命 | 持续反胃 I |
| 恢复到至少 20 | 停止后续缺水伤害 | 已有反胃自然结束，最多约残留 10 秒 |

缺水伤害可以致死。普通缺水与口渴归零之间切换时，伤害间隔重新计时。

## 温度

### 状态与伤害

| 温度值 | 状态 | 对其他状态的影响 |
| ---: | --- | --- |
| 0–14 | 寒冷 | 体力恢复 ×0.5；理智 −2／分钟 |
| 15–34 | 冷 | 体力恢复 ×0.8；理智 −1／分钟 |
| 35–65 | 正常 | 无冷热惩罚 |
| 66–84 | 热 | 失水 ×1.25；理智 −1／分钟 |
| 85–100 | 炎热 | 失水 ×1.5；理智 −2／分钟 |

临界值附近的图标有约 2 点缓冲，避免反复闪烁。上述联动只作用于仍然开启的状态。

| 危险情况 | 伤害 |
| --- | --- |
| 温度低于 15 | 每 8 秒扣 1 点生命 |
| 温度低于 15，且身体在水中 | 每 2 秒扣 1 点生命 |
| 温度达到 85 或更高 | 每 8 秒扣 1 点生命 |

温度伤害可以致死，即使其他三项状态关闭也会生效。离开危险温度后，伤害计时归零。

### 温度怎样变化？

环境决定一个“目标温度”，当前温度逐渐向它靠近。下文“目标＋／−”表示环境变化，不会立刻改掉当前温度。

| 情况 | 当前温度的变化速度 |
| --- | --- |
| 通常情况 | 每秒最多向目标移动 1 点 |
| 目标恰为 50 | 每秒最多移动 2 点 |
| 吃完四种汤煲 | 当前温度立即 ＋8 |
| 陷入细雪 | 约 1 秒内降到不高于 5，详见“细雪” |

天气、落水、滑翔、着火、皮革护甲和抗火效果还会调整变化速度，见对应表格。当前值与目标均限制在 0–100。

### 群系与昼夜

| 地点 | 基础目标温度 |
| --- | --- |
| 普通主世界群系 | 50 |
| 亚热带：丛林、竹林及丛林变体，暖海、深暖海 | 60 |
| 沙漠、恶地及其变体 | 白天 75，夜晚 30 |
| 寒冷群系及其变体 | 白天 25，夜晚 15 |
| 热带草原及其变体 | 75 |
| 末地 | 35 |
| 下界 | 85 |

寒冷群系包括冰雪群系、寒冷针叶林、冷海、冻海、冷海滩及相关变体。未列入特殊分类的群系按普通主世界群系处理。

亚热带仍叠加普通环境修正：日晒 ＋5、露天夜晚 −6、淋雨 −8、入水 −10；当前温度逐渐趋近目标。

沙漠、恶地和寒冷群系的昼夜变化如下：

| 时段 | 游戏时间 | 基础目标 |
| --- | --- | --- |
| 白天 | 1000–11000 | 保持白天值 |
| 黄昏 | 11000–14000 | 逐渐从白天值降到夜晚值 |
| 夜晚 | 14000–22000 | 保持夜晚值 |
| 黎明 | 22000–次日 1000 | 逐渐从夜晚值回升到白天值 |

- 这些群系在室内也有昼夜温差；屋顶只能挡日晒和降水。
- 不再额外扣除下表中的露天夜晚 −6。
- 寒冷群系夜晚的基础目标 15 本身不会造成冻伤；淋雨、湿身、饥饿或高海拔仍可使温度降到 15 以下。

### 天气、地形与身体状态

| 因素 | 目标或速度变化 |
| --- | --- |
| 露天晴天，时间 1000–11000，天空光照至少 14 | 目标 ＋5 |
| 露天雨／雷雨，且不在炎热群系 | 目标 −8；修正后目标仍低于 50 时，降温速度 ×1.5 |
| 主世界露天夜晚，时间 14000–22000 | 目标 −6；室内不扣，沙漠、恶地和寒冷群系使用自己的昼夜规则 |
| 主世界 Y>96 | 每上升 32 格，目标约 −4，最多 −20；下界、末地不适用 |
| 鞘翅实际滑翔 | 目标 −6，降温速度 ×1.5 |
| 身体入水 | 目标 −10；寒冷群系改为 −20；温度变化速度 ×3 |
| 离开水或雨后的湿身 | 目标先 −5，再逐渐回到 0；通常最多 90 秒，火源或日晒下约 30 秒变干 |
| 饱食度不高于 6，且此前目标低于 50 | 目标 −5；饱食度为 0 时改为 −10 |
| 每件干燥皮革护甲 | 目标 ＋2，降温速度 −12.5%；四件共 ＋8、−50% |
| 吃完蘑菇煲、兔肉煲、甜菜汤或谜之炖菜 | 当前温度立即 ＋8 |
| 处于抗火效果中，且环境目标高于 50 | 目标 −20，最低降到 50；升温速度 ×0.5 |

- 浸水或湿身时，皮革护甲不保温；湿身降温不与当前淋雨、入水的降温重复叠加。
- 湿身在退出、重进后保留，离线不会变干；死亡、关闭温度或离开生存／冒险模式会清除。
- 游泳产热可以减缓失温，但不能免疫冷水。无其他修正时，寒冷群系夜间落水的目标为 15−20，截为下限 0。

- 抗火隔热按实际药效生效；药效过期或被牛奶清除后恢复原规则，重复喝药或提高效果等级不会叠加。
- 不会瞬间降低当前体温，不改变正常／寒冷环境和细雪规则，也不新增温度伤害豁免。
- 例如：下界无其他修正时，目标从 85 降为 65；已封顶到 100 的目标降为 80。

### 火焰保护附魔

| 项目 | 本包隔热效果 |
| --- | --- |
| 穿着的四个护甲槽 | 火焰保护等级相加，每累计一级削减热源过热贡献的 5% |
| 单件火焰保护 IV | 削减 20% |
| 四件均为火焰保护 IV | 削减 80%，达到上限 |

- 只削减附近热源及玩家着火把目标推到 50 以上的那部分热量；寒冷时取暖至 50 的部分保留。
- 不降低群系／维度基线、日晒或活动产热，也不改原版附魔的伤害防护。背包和副手中的附魔护甲不生效。
- 例如常温目标 50、附近火源 ＋20：单件 IV 后目标为 66，四件 IV 后为 54；寒冷目标 25、火源 ＋20 时仍为 45。
- 可与抗火药效一起使用：先结算附魔，再结算药效。换装后在下一次温度结算生效，通常最多约 1 秒。

### 附近冷热源

有效范围为水平 4 格内、脚下一层到头部附近。下表是目标温度的变化，不是当前温度立即变化的数值。

| 来源 | 距离不超过 1 格 | 2 格 | 3 格 | 4 格 |
| --- | ---: | ---: | ---: | ---: |
| 火、篝火、灵魂篝火 | ＋20 | ＋15 | ＋10 | ＋5 |
| 熔岩 | ＋30 | ＋23 | ＋15 | ＋8 |
| 燃烧中的熔炉、高炉、烟熏炉 | ＋15 | ＋11 | ＋8 | ＋4 |
| 岩浆块 | ＋10 | ＋8 | ＋5 | ＋3 |
| 雪块、雪层、细雪 | −5 | −4 | −3 | −1 |
| 冰块 | −10 | −8 | −5 | −3 |
| 浮冰 | −15 | −11 | −8 | −4 |
| 蓝冰 | −20 | −15 | −10 | −5 |

- 越远效果越弱，斜向按直线距离计算；超过 4 格无效。
- 多个热源只取最强的一个，多个冷源也只取最强的一个；冷热效果相减，不会无限叠加。
- 三种炉子停止燃烧后不提供热量；岩浆块可在脚下一层取暖。新热源也沿用加快湿身干燥的规则。
- 玩家着火相当于至少 ＋20 的热源，与附近热源取较大者；升温速度 ×3。
- **寒冷群系禁用附近冰雪的额外降温**，火源取暖及其他温度规则不受影响。
- 下界、末地和其他非寒冷群系仍可利用冰雪降温。

### 运动产热

| 动作 | 对当秒目标的加成 |
| --- | --- |
| 行走 | 持续一整秒 ＋1 |
| 冲刺 | 持续一整秒 ＋5 |
| 游泳 | 持续一整秒 ＋4 |
| 挖掘 | 持续一整秒 ＋2 |
| 跳跃、攻击挥动 | 每次 ＋2 |

- 持续动作不足一秒时按时长折算，与跳跃、挥动的加成相加，当秒总加成最多 ＋10。
- 每秒重新计算，停止动作后对应加成消失，不会逐秒永久累积。
- 关闭体力或口渴不会关闭运动产热。

### 细雪

- 身体陷入细雪后，约 1 秒内将高于 5 的温度降到 5；原本低于 5 不会被抬高，其他因素仍可继续降温。
- 留在细雪中时，目标温度不超过 5，火源、皮革和运动无法使温度维持在 5 以上。
- 单纯站在细雪表面、站在普通雪块或雪层上，不会直接降到 5；非寒冷群系仍会受到附近冷源的缓慢降温。
- **陷入细雪的直接降温在寒冷群系也生效。** 离开后按普通环境逐渐回温，不立即恢复到 50。
- 细雪不会额外补水或增加湿身。原版细雪冻伤不由本包的温度开关控制。

## 理智

### 消耗与恢复

| 条件 | 理智变化 |
| --- | --- |
| 饱食度不高于 6／20 | −1／分钟；饱食度为 0 时 −2／分钟 |
| 口渴低于 20 | −1／分钟；口渴为 0 时 −2／分钟 |
| 温度为冷或热 | −1／分钟 |
| 温度为寒冷或炎热 | −2／分钟 |
| 身处下界 | −0.5／分钟 |
| 头部光照不高于 4，连续至少 30 秒 | −2／分钟；离开暗处后，这段黑暗累计清零 |
| 距上次睡觉至少 2 个游戏日 | −1／分钟；达到 3 个游戏日后 −2／分钟 |
| 无上述持续压力、头部光照至少 8、温度正常 | ＋3／分钟 |
| 睡觉 | 一次 ＋20，重置缺觉；至少隔半个游戏日才能再次获得奖励 |

- 持续消耗合计最多 −3／分钟，包括下界压力。
- 关闭口渴或温度后，不计对应压力；温度关闭时，自动恢复不再要求温度正常。
- 光照 5–7 时不触发安全环境恢复。下界始终有压力，无法靠上述安全环境恢复，但仍可以听音乐。

### 受伤

每受 1 点伤害扣 1 点理智，单次最多扣 8 点；每 60 秒在线时间合计最多扣 12 点。本包的缺水伤害不会再扣一次理智。

### 听音乐

| 条件 | 理智变化 |
| --- | --- |
| 正在播放唱片的唱片机 8 格以内，距离包含高度差 | 额外 ＋2／分钟 |
| 安全环境恢复与音乐同时满足 | 合计 ＋5／分钟 |
| 持续压力达到每分钟 −3 的上限，同时听音乐 | 净 −1／分钟；受伤扣除仍另算 |

- 多个唱片机不叠加。歌曲结束、取出唱片或离开范围后停止音乐恢复，约 1 秒内生效。
- 音乐可以抵消部分持续压力，不清除饥饿、缺水、冷热、缺觉等状态，理智最多恢复到 100。
- 只计算实际播放的唱片机，不计算背景音乐、环境音或命令播放的音效；按播放状态判定，不读取个人音量设置。
- 关闭理智机制后，音乐恢复也停止；其他状态的开关不影响音乐恢复。

### 低理智效果

| 触发条件 | 效果 | 恢复条件 |
| --- | --- | --- |
| 从至少 75 跌到低于 75 | 速度 I，持续 6 秒 | 再次触发前，须曾恢复到 100，且从上次触发起至少在线经过 1 个游戏日，之后再次跌破 75 |
| 低于 50 | 每隔随机 45–90 秒获得一次虚弱 I，持续 5 秒 | 理智恢复到至少 53 |
| 低于 25 | 持续黑暗；每隔随机 45–90 秒播放仅自己听见的洞穴环境音 | 理智恢复到至少 28 |

速度效果的“一天”按 24000 个在线游戏刻计算，正常速度下约 20 分钟。离线和睡觉跳过夜晚不会缩短这段等待。

## 适配版差异

| 项目 | 适配版规则 |
| --- | --- |
| 近战 | 命中 −2 体力、−0.05 口渴，暂停体力恢复 0.5 秒；挥空不计费 |
| 挖掘 | 成功破坏方块 −1 体力、−0.025 口渴；不按挖掘时长扣除，未挖成不计费 |
| 体力耗尽后的限制 | 保留禁跳、阻止破坏及原版弓／弩使用、冲刺／游泳限速；无法保证阻止近战或投射物伤害 |
| 温度动作产热 | 挥空和未完成的挖掘不产热；命中、成功破坏方块各使当秒目标 ＋2；行走、冲刺、游泳和跳跃不变 |
| 细雪 | 降温规则相同；旧版以估算的身体范围判定接触，特殊体型或姿态的边缘判定可能不同 |
| 水瓶、普通饮用药水 | 统一补口渴 20；牛奶仍 ＋20，四种汤煲仍补口渴 ＋10、温度 ＋8 |

未列出的规则与完整版相同。蜂蜜瓶、不祥之瓶仍不补水，喷溅／滞留药水仍不算饮用。适配版的攻击限制不能作为战斗防作弊手段。

## 命令接口

以下供管理员和地图作者使用，需要世界允许作弊及相应权限。

### 命令方块控制全世界开关

```mcfunction
scriptevent ot:status_toggle stamina off
scriptevent ot:status_toggle stamina on
```

- `on` 开启，`off` 关闭，与面板控制同一份世界设置。
- 将 `stamina` 换为 `thirst`、`temperature` 或 `sanity`，即可控制对应状态。
- 此接口只接受命令方块来源；旧通用包的 `ot:feature_toggle` 不控制本包。

### 读取数值

四个计分目标记录四舍五入后的整数，只用于读取。修改分数不会改变真实状态；关闭状态后，分数保留。

体力、口渴通常每游戏刻同步，温度、理智约每秒同步。创造模式也可以读取保存的值。

检测体力不高于 20 的玩家：

```mcfunction
execute as @a[scores={ot_stamina=..20}] run title @s actionbar 体力不足
```

在循环命令方块中显示全部数值：

```mcfunction
execute as @a run titleraw @s actionbar {"rawtext":[{"text":"体力 "},{"score":{"name":"@s","objective":"ot_stamina"}},{"text":"  口渴 "},{"score":{"name":"@s","objective":"ot_thirst"}},{"text":"  温度 "},{"score":{"name":"@s","objective":"ot_temperature"}},{"text":"  理智 "},{"score":{"name":"@s","objective":"ot_sanity"}}]}
```

不需要显示时停用该命令方块。动作栏由多个功能共用，其他文字可能覆盖此显示；建议关闭重复命令方块的聊天反馈。

### 设置自己的测试值

管理员在聊天栏使用：

```mcfunction
/scriptevent ot:stamina_test 25
/scriptevent ot:thirst_test 20
/scriptevent ot:temperature_test 50
/scriptevent ot:sanity_test 100
```

| 参数 | 作用 |
| --- | --- |
| 0–100 整数 | 修改自己的真实数值 |
| `on` | 开启个人测试显示；温度设为 50，其余状态设为 100 |
| `off` | 退出个人测试显示，不关闭世界机制 |

- 测试值不会冻结。生存、冒险模式仍会正常变化并触发惩罚；创造模式仅显示测试条。
- 世界开关关闭时，个人测试也不能显示对应状态。
- 测试接口仅供管理员本人使用，不能通过命令方块给普通玩家修改真实数值。

## 存档与常见问题

| 情况 | 说明 |
| --- | --- |
| 更新同一版本类型的包 | 保留已有状态值、个人位置和世界开关 |
| 首次启用独立包、切换完整版与适配版 | 尽量继承现有计分数值和世界开关；读取不到时使用初始值，未设置的开关默认开启 |
| 切换包后的计时 | 湿身、睡眠记录和惊慌冷却不能完整继承，可能重新计时；不会删除旧数据 |
| 首次进入正在下雨的世界 | 降水降温、淋雨补水可能需要等下一次天气变化才生效 |
| 叠加其他 HUD 资源包或频繁使用标题命令 | 可能影响本包显示 |
| 特殊屋顶、水浸方块或 GUI 缩放 | 遮雨、接触或显示边界可能存在差异，需要在对应设备上确认 |

升级或切换包前建议备份世界。撤包前先关闭体力，或让受限玩家恢复到至少 20。

如果撤包后仍无法跳跃，管理员可执行：

```mcfunction
/inputpermission set @s jump enabled
```
