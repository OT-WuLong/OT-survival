# OT 生存包源码目录

本目录集中保存完整版与适配版源码、原始纹理、构建工具和专用测试。玩法与数值统一写在数值说明，不在本页重复。

## 文档入口

| 文档                                                    | 内容                                           |
| ------------------------------------------------------- | ---------------------------------------------- |
| [数值说明](pack/数值说明.md)          | 两版数值、适配差异、面板、命令及存档说明 |
| [开发笔记](开发笔记.md)                                  | 实现结构、数据接口、历史错误及验证边界         |

两版说明与原“四项状态数值基线”统一合并到 `pack/数值说明.md`；以后调参只维护这份文件。

## 目录

| 目录                                | 内容                                     |
| ----------------------------------- | ---------------------------------------- |
| `pack/ot_survival_status/`        | 完整版行为包、资源包、安装文件 |
| `pack/ot_survival_status_compat/` | 适配版行为包、资源包、独立及合并安装文件 |
| `assets/textures/`                | 状态条原始纹理，修改后需手动同步资源包   |
| `tools/`                          | HUD 图像控件生成器与控件／绑定数量检查   |
| `scripts/`                        | HUD 定位及位置面板生成器                 |
| `tests/`                          | 生存包专用自动测试                       |

## 开发命令

修改包发布版本前，先阅读 [版本维护约定](AGENTS.md)。

在本目录运行，使用现有 Node.js，无需添加依赖：

```powershell
npm test
npm run build
npm run hud:inspect
```

`build` 重建两版资源包的 HUD 和位置面板 JSON，不生成或更新 `.mcaddon`。修改运行文件后仍须重新打包.

在地图项目根目录也可运行 `npm run test:survival`、`npm run build:survival`。根目录 `npm test` 运行全部检查.
